# Ethan Campbell Resume Website

[ecampbell.dev](https://ecampbell.dev)

This repository is my personal portfolio website, built with Hugo and Hugo Profile.
It includes my professional experiences and skills, as well as how to contact me.

## Overview

- Built using Hugo.
- Using Hugo Profile, as a submodule.
- Deploy to Hetzner with a SFTP based github action.

## Repository Structure

- [hugo.yaml](hugo.yaml) — this is where almost all customization happens.
- [layouts/](layouts/) — These layouts are to override the theme wanting to use local fontawesome, by using a CDN.
- [static/](static/) — All static files, pictures, resume.
- [themes/hugo-profile/](themes/hugo-profile/) — the underlying Hugo theme submodule
- [.github/workflows/deploy-to-hetzner.yml](.github/workflows/deploy-to-hetzner.yml) — deployment workflow for publishing the site

## Local Development

### Prerequisites

- Hugo
- Git

### Run locally

1. Clone the git repo

2. run the hugo server
   ```bash
   hugo server
   ```
The site is always written to the [public/](public/) directory, which is the only bit that needs updated.


## Remote deployment.

The [deploy-to-hetzner.yml](.github\workflows\deploy-to-hetzner.yml) deploys all files to Hetzner webhosting using SFTP.
It also deletes the fontawesome-6 folder that is generated by the submodule. The folder is not needed due to overriding layouts to use CDN.
